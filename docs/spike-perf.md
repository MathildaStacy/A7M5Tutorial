# Android 相机预览性能记录

2026-11-24。测试使用内置 v2 LOD0 模型的 ARM64 Preview APK，在 Android API 37 模拟器执行。显示分辨率为 1280 × 2856，密度为 480 dpi，WebView 版本为 156.0.8078.47。模拟器通过 ANGLE / SwiftShader 进行软件渲染。

| 项目 | 观测结果 | 量取方式 |
|---|---:|---|
| 进入相机到看到模型 | 4.20–6.83 秒 | 强制停止应用、重新启动到学习页，再点「相机」。以连续录取的屏幕截图与稳定模型图像比对，上下界分别是最后一张未出现模型的截图与第一张命中的截图。保留了已安装应用的缓存。 |
| 连续旋转时的画面呈现 | 6.50 帧/秒 | 连续两次反向拖动，读取 SurfaceFlinger 的 Activity 图层。50 次新呈现的首尾间隔为 7.54 秒。 |
| 单个相机 WebView 打开后的应用 PSS | 196,439 KiB，约 192 MiB | 停止拖动后执行 `dumpsys meminfo com.shutteracademy`，读取应用进程的 TOTAL PSS。WebView 的独立渲染进程及 GPU 共享开销未合入。 |

软件渲染时，绘图分辨率以每 CSS 像素一个采样像素为上限。首帧会先完成阴影、透射和显示屏的渲染，再通知原生界面开始发送操作指令。APK 与评审渲染使用相同的几何与材质。[渲染实现](../src/camera3d/main.ts) · [模型评审](reviews/model-v2/README.md)
