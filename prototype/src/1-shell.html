      AI 教练怎么工作

      Agent 循环跑在手机上。模型看照片和 EXIF，边讲边调用本地工具：在 3D 相机上高亮按键、演示拨盘转几格、在照片上画框。工具全部在客户端执行，结果再回传给模型。

      sequenceDiagram
  participant U as 用户
  participant A as App（Agent 循环）
  participant M as 模型服务
  participant T as 本地工具
  U->>A: 上传照片 + 拍摄意图
  A->>A: 解析 EXIF、缩放、对焦点裁切、移除 GPS
  A->>M: 系统提示 + 工具定义 + 照片 + EXIF
  M-->>A: 流式文本 + tool_use / function_call
  A->>T: highlight_control、annotate_photo …
  T-->>A: 3D 高亮、照片标注的执行结果
  A->>M: tool_result / function_call_output
  M-->>A: 复盘卡 + end_turn
  A->>U: 对话、3D 演示、复盘卡

      技术选型：沿用 QuantWise

      • React Native 0.87 + TypeScript，react-navigation 7、zustand、op-sqlite、react-native-keychain，和 QuantWise 一致。
      • AI 层直接移植 QuantWise 的 src/ai/（双协议请求构建、SSE、工具循环、Key 存储、mock 服务），只新增图片输入和相机工具集。
      • 3D 用 react-native-webview + three.js。这个原型里的 3D 相机代码就是将来搬进 App 的那一份。
      • WebView 在中端机上达不到 60fps 时，换 react-native-filament，部件 ID 不变。
